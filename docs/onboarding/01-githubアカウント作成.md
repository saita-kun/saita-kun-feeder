# 01. GitHub アカウント作成

すでにアカウントがある方は [02-claude-codeセットアップ.md](02-claude-codeセットアップ.md) へ。

1. ブラウザで https://github.com/ を開き、「Sign up」から無料アカウントを作成します（メールアドレスとパスワードのみ）。
2. 会社用・個人用どちらのアカウントでも構いません。このキットの repo は **private（非公開）** で作るため、社名等が公開されることはありません。
3. 無料プランで十分です（private repo・GitHub Actions の無料枠内で動作します）。

作成できたら [02-claude-codeセットアップ.md](02-claude-codeセットアップ.md) へ進んでください。
