# 03. このキットを自分のものにする

## 1. テンプレートから自分専用の repo を作る

1. ブラウザで https://github.com/saita-kun/saita-kun-feeder を開きます。
2. 緑の「Use this template」→「Create a new repository」をクリック。
3. Repository name は自由（例: `my-subsidy-feeder`）。
4. **Visibility は必ず「Private」を選択**してください。あなたの会社のプロファイルを置くためです（public のままでは `/setup` が先に進みません）。
5. 「Create repository」で作成。

このキットは「テンプレート」方式です。fork ではなくコピーが作られ、あなたの repo はあなたの所有物になります。上流の改善は後から `tools/update-core.sh` で取り込めます（[manual.md](../manual.md)）。

## 2. 手元に clone して Claude Code で開く

```bash
gh repo clone <あなたのアカウント>/<repo名>
cd <repo名>
claude
```

## 3. /setup を実行

Claude Code で `/setup` と入力してください。以降は AI が案内します:

- 環境チェックと private 確認
- 利用規約の確認・同意
- 会社プロファイルの聞き取り（所在地・業種・使いたい用途・従業員数）
- お試し実行（実際のマッチ結果を画面で確認）

その後 `/setup-channel` で通知の届け先を設定すれば、毎朝の自動配信が始まります。
