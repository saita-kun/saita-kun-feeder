# 03. このキットを自分のものにする

## 1. テンプレートから自分専用の repo を作る

1. ブラウザで https://github.com/saita-kun/saita-kun-feeder を開きます。
2. 緑の「Use this template」→「Create a new repository」をクリック。
3. Repository name は自由（例: `my-subsidy-feeder`）。
4. **Visibility は必ず「Private」を選択**してください。あなたの会社のプロファイルを置くためです（public のままでは `/setup` が先に進みません）。
5. 「Create repository」で作成。

このキットは「テンプレート」方式です。fork ではなくコピーが作られ、あなたの repo はあなたの所有物になります。上流の改善は後から `tools/update-core.sh` で取り込めます（[manual.md](../manual.md)）。

## 2. 手元に clone して AI エージェントで開く

作った repo を自分のパソコンにコピー（clone）します。**やり方は 3 つのうちどれでも構いません**（`gh` は任意です）。

**A. `git clone` を使う**（`gh` 不要。private repo なので GitHub の認証を求められます）

```bash
git clone https://github.com/<あなたのアカウント>/<repo名>.git
cd <repo名>
```

パスワードを聞かれた場合は、GitHub のパスワードではなく[個人アクセストークン（PAT）](https://github.com/settings/tokens)を入力します。

**B. GitHub CLI（`gh`）を使う**（`gh auth login` 済みなら認証入力が不要です）

```bash
gh repo clone <あなたのアカウント>/<repo名>
cd <repo名>
```

**C. GUI アプリを使う**（コマンドが苦手な方向け）

- [GitHub Desktop](https://desktop.github.com/) の「Clone a repository」から自分の repo を選ぶ
- または VS Code のコマンドパレットで `Git: Clone` を実行する

clone したフォルダを、お使いの AI コーディングエージェントで開きます（Claude Code なら、そのフォルダで `claude` を実行）。

## 3. /setup を実行

Claude Code で `/setup` と入力してください（slash command が無いエージェントの場合は「`.claude/commands/setup.md` を読んで手順どおり進めて」と依頼してください）。以降は AI が案内します:

- 環境チェックと private 確認
- 利用規約の確認・同意
- 会社プロファイルの聞き取り（所在地・業種・使いたい用途・従業員数）
- お試し実行（実際のマッチ結果を画面で確認）

その後 `/setup-channel` で通知の届け先を設定すれば、毎朝の自動配信が始まります。
