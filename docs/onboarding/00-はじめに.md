# 00. はじめに

このキット（サイタくんフィーダー）は、自社に合う補助金の新着情報を、毎朝あなたの Slack やメールに自動で届けるための道具です。プログラミングの知識は不要で、AI（Claude Code）が設定を伴走します。

## 必要なもの

1. **GitHub アカウント**（無料）— このキットのコピーを自分専用に持つため → [01-githubアカウント作成.md](01-githubアカウント作成.md)
2. **Claude Code**（Anthropic の AI ツール）— 設定・チャネル実装を AI に任せるため → [02-claude-codeセットアップ.md](02-claude-codeセットアップ.md)
   - （Codex CLI・Cursor など他の AI コーディングエージェントでも動きます。slash command が無い環境では「`.claude/commands/setup.md` を読んで手順どおり進めて」と依頼してください — [AGENTS.md](../../AGENTS.md) 参照）
3. **POSIX シェルが動くパソコン**（macOS / Linux、または Windows なら WSL2）— Windows ネイティブ（PowerShell・コマンドプロンプト）は非対応です。Windows の方は WSL2 を導入し、その中でこのキットを使ってください。
4. 約 30 分の初回セットアップ時間

## 進め方

上の 1〜3 が揃ったら [03-このキットを自分のものにする.md](03-このキットを自分のものにする.md) に進み、自分専用の private repo を作って Claude Code で `/setup` を実行してください。以降は AI が案内します。

## 利用できる方

**自社のために使う事業者本人**（法人・個人事業主）です。支援機関・代行業者がクライアント向けに使うことは利用規約で禁止されています（[TERMS.md](../../TERMS.md) 第 2 条）。
