# 02. Claude Code セットアップ

すでに Claude Code が使える方は [03-このキットを自分のものにする.md](03-このキットを自分のものにする.md) へ。

1. https://claude.com/claude-code の公式手順に沿ってインストールします（Claude の有料プランまたは API アカウントが必要です）。
2. デスクトップアプリ版・ターミナル（CLI）版のどちらでも本キットは動作します。
3. あわせて GitHub CLI（`gh`）があると設定がスムーズです: https://cli.github.com/ の公式手順でインストールし、`gh auth login` でログインしておきます（`/setup` の private 確認と Secrets 登録に使います）。

準備ができたら [03-このキットを自分のものにする.md](03-このキットを自分のものにする.md) へ進んでください。
