# データの扱い（やさしい版）

正式な条文は [TERMS.md](../TERMS.md)、データガバナンスの親規範は [docs/governance/data-charter-link.md](governance/data-charter-link.md) です。このページは平易なまとめです。

## あなたのデータはどこにも送られません

- 会社プロファイル（所在地・業種・従業員数など）は、**あなたの private repo の中**にだけあります。
- マッチングの計算も、あなたの repo（GitHub Actions またはあなたのパソコン）の中で行われます。
- 提供側（サイタくん）には、誰が使っているか・何がマッチしたかを含めて**一切送信されません**。利用統計も取りません。

## 自動で行われる外部との通信は 2 つだけ

1. **補助金データの受信**: 公開データフィード（誰でも読める静的ファイル）をダウンロードします。読むだけで、何も送りません。
2. **あなたが設定した通知先への送信**: `/setup-channel` であなたが作った送信先（Slack・メールなど）へ、あなたのダイジェストを送ります。

このほかに、**あなたが明示的に同意した場合だけ**行われる任意操作があります: セットアップ完了時に AI が「スターとフォローで応援しますか？」と一度だけ確認し、同意した項目だけを**あなたの GitHub アカウントから**実行します（ADOPTERS 掲載の Issue 投稿も同様に任意です）。同意しなければ何も実行されず、提供側にあなたのデータが送られることもありません。

## 置き場所のルール

| データ | 置き場所 | 公開されるか |
|---|---|---|
| 会社プロファイル | `profile/`（private repo にコミット） | されない（private） |
| 配信履歴の台帳 | `state/notified.json`（補助金 ID とハッシュのみ） | されない（private） |
| 同意の記録 | `input/`（git 管理外・手元のみ） | されない |
| webhook URL・パスワード類 | GitHub Secrets / 環境変数のみ | されない（ファイルに書かない） |

## 受け取ったデータのライセンス

補助金データフィードは CDLA-Permissive-2.0 で無料公開されています。社内での利用・加工は自由です。ただし本キットを使った社外への再配信は自社利用の範囲外です（TERMS 第 2 条）。
